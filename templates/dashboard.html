    AI Model Architecture

    This system uses an ensemble of three distinct machine learning models to evaluate transaction risk.

    XGBoost Classifier Supervised Learning

    Trained on historical labeled fraud data. Excels at finding known fraud patterns.

    LSTM Network Sequential Analysis

    Analyzes the previous 5 transactions of the destination account to detect suspicious behavioral sequences.

    Autoencoder Anomaly Detection

    Unsupervised model. Flags transactions that deviate from normal statistical patterns (high reconstruction error).
